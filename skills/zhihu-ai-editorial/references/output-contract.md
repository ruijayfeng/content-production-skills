# 每日工作台输出契约

输出使用中文 Markdown，结论先行，所有链接可点击。

## 1. 今日结论

- 建议发 / 建议实测后再发 / 今天不建议发；
- 一句话说明最重要的变化和选择理由；
- 时间窗口、采集来源数、失败来源数、新增条目数。

## 2. 新增情报摘要

按“新发布 / 新进展 / 新发现”分组。每条包含标题、发生了什么、原始来源、时间口径和事实置信度。最多 12 条。

## 3. 候选题卡

最多 5 张，按编辑评分排序。每张必须包含：

- 工作标题（不是夸张标题）；
- 目标读者与具体任务；
- 为什么现在值得做；
- 知乎需求证据与现有回答缺口；
- 可形成的独有证据；
- 评分明细与总分；
- 原始来源；
- 主要风险与淘汰条件；
- 建议：现在做 / 观察 / 放弃。

## 4. 候选题对比与确认区

使用稳定题目 ID 列出：

- 系统排序与推荐理由；
- 各题之间最重要的差异；
- 预计所需证据与获取难度；
- 最大风险和放弃条件；
- 用户反馈：会写 / 不写 / 观察 / 合并；
- 用户选择的切入角度与备注。

## 5. 最终选题确认

记录：

- 已确认题目 ID 与工作标题；
- 目标读者和要解决的具体问题；
- 已确认的切入角度；
- 支持选择的关键来源；
- 需要交给下游独立 Skill 的已知约束；
- 或明确记录“本轮不写”。

到此停止。不得生成研究报告、实测计划、文章大纲、正文、文风文本、配图或平台排版。

## 6. 观察池与采集健康

列出 1–3 个暂不值得写的信号和原因，以及本次失败或降级的来源。让作者知道系统没看到什么。
