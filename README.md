# Content Production Skills

我的内容生产工作流 Skills 仓库。

这个仓库用于沉淀从选题、写作、配图到平台发布前适配的一整套可组合工作流。每个 Skill 独立负责一个清晰环节，可以单独使用，也可以在后续串成完整生产线。

## 已有 Skill

### zhihu-ai-editorial

知乎 AI / 科技内容灵感雷达。

它负责：

- 从公开信息源增量收集 AI 与科技动态；
- 合并同一事件，保留原始来源；
- 按当天变化整理方向和灵感卡；
- 标记新鲜度、可实测性和持续变化；
- 展示各信息源的成功、失败和更新状态。

它是找灵感、看方向的轻量工具，不使用严格选题门槛或复杂评分。它不负责资料深挖、实测、文章结构、正文、个人文风、去 AI 感、配图、平台排版或发布。

## 仓库原则

- 一个 Skill 只解决一个清晰问题；
- 已完成的 Skill 才进入 skills 目录，不用空壳占位；
- 事实、推断、作者经验和平台规则明确区分；
- 默认不保存账号凭证，不绕过平台限制；
- 默认不自动发布，发布决定由作者保留；
- 先用真实任务跑通，再根据反馈迭代。
