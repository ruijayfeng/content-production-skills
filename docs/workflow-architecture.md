# 内容生产工作流架构

## 总体结构

每个 Skill 都是一个可独立运行的模块，通过清晰交付物连接，而不是做成一个不断膨胀的万能 Skill。

| 上游 Skill | 交付给下游的内容 | 下游 Skill |
|---|---|---|
| 选题 | 已确认题目、目标读者、切入角度和关键来源 | 后续研究或写作 |
| 写作 | 已确认正文、段落意图、配图需求 | 配图 |
| 写作 + 配图 | 完整图文内容与视觉资产 | 公众号排版 |
| 写作 + 配图 | 可拆分主题、图文素材与事实依据 | 小红书图文 |

## 责任边界

### 选题 Skill

回答“什么值得写、为什么现在写、最终确认写什么”。确认题目与切入角度后停止，不负责资料深挖、实测或任何内容生产。

### 写作 Skill

回答“这篇文章怎样展开并保持作者表达”，不重新决定选题，也不编造实测。

### 配图 Skill

回答“哪里需要什么视觉信息、怎样保持 IP 一致”，不改变文章事实和观点。

### 平台适配 Skill

回答“同一内容怎样适应特定平台”，不为了平台风格篡改事实或伪造互动。

## 共享原则

- 每个重要事实保留来源；
- 作者经历只能来自作者本人提供的材料；
- 中间产物可审查、可修改、可追溯；
- 自动化只处理已授权范围；
- 任何平台发布动作都需要单独明确授权。
